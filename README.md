# Gregory Schilsson – Resume

A single‑file Markdown resume that uses YAML front‑matter and is rendered as a clean, responsive web page via GitHub Pages (Jekyll).  
The repo contains:

- `docs/resume.md` – the full Markdown resume with front‑matter
- `_config.yml` – Jekyll configuration for Pages
- `_layouts/default.html` (optional) – minimal layout for rendering

## View the live site

[https://gregsonian.github.io/resume/](https://gregsonian.github.io/resume/)

## Usage

1. Clone the repo  
   `git clone https://github.com/gregsonian/resume.git`
2. Edit `resume.md` locally and commit changes  
   `git add resume.md && git commit -m "Update resume"`
3. Push to GitHub – the site updates automatically.
